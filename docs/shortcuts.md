# Keyboard shortcuts

These are the Linux shortcuts. The text editor uses one selection at a time.

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New scratch buffer |
| Ctrl+O | Open a file |
| Ctrl+S | Save the current buffer |
| Ctrl+Shift+S | Save As |
| Ctrl+W | Close the tab to the shelf |
| Ctrl+Shift+T | Reopen the most recently closed buffer |
| Ctrl+Shift+R | Name the active unsaved scratchpad |
| Ctrl+P | Switch open buffers |
| Ctrl+Shift+P | Open the command palette |
| Ctrl+F | Open Find |
| Ctrl+G | Show Go to line controls |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+A | Select all in the focused text field |
| Ctrl+Shift+W | Toggle word wrap |
| Ctrl++ or Ctrl+= | Increase editor font size |
| Ctrl+- | Decrease editor font size |
| Ctrl+, | Open Appearance |
| Ctrl+F2 | Add or remove a bookmark at the cursor |
| F2 | Go to the next bookmark |
| Shift+F2 | Go to the previous bookmark |
| Esc | Close search, the palette, or buffer-tool windows |

Use **More → Browse closed buffers…** to reopen an older shelf entry and
**More → Bookmarks…** to browse saved positions. The **CUDA** panel exposes its
debugging controls as buttons.

Undo/redo in a search or debugger input edits that input. In the document editor,
it uses the buffer's history.
