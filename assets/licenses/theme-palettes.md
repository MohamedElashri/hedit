# Additional theme palettes

These palettes adapt upstream colors to hedit's interface and syntax roles.
The application uses opaque selections; secondary text and accents are adjusted
where needed to retain readable native controls. The theme picker, appearance
gallery, and exported JSON files all use the same built-in catalog.
