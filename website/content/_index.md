## Find an answer

Use **Search docs** to find a setting, shortcut, API, or permission. The
[keyboard reference](@/guide/shortcuts.md) lists platform-specific bindings.
The same user guide is available inside hedit with **F1**, including when you are offline.

## Follow a complete example

Plugin authors can start with [a small document command](@/plugins/first-plugin.md),
then explore the shipped [provider and service examples](@/plugins/examples.md).
Each example has fixtures you can run with the editor's CLI.
